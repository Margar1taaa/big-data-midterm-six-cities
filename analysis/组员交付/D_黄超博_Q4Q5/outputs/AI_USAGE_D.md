# AI 使用说明（D：Q4城市差异与Q5聚类）

使用工具：OpenAI Codex。使用时间：2026-10-28—29；2026-11-03由负责人完成人工复核。

| 阶段 | 任务/Prompt 摘要（非逐字转录） | 采用、修改或放弃 | 验证方式 |
|---|---|---|---|
| 人口和来源 | 对账30条普查人口、检查插值与点位来源，整理来源卡 | 采纳人口来自Census Table 4、NHGIS只提供1930点位；放弃把人口称为NHGIS人口 | 按六份普查卷页码人工逐条核对30条记录 |
| Q4分析 | 比较城市人口、报刊关注和疫情指标，生成城市散点图 | 修改后采纳：白喉作为主分析，按共同有效周和完整滚动窗口计算；缺失保持NA | 独立重算人口插值、命中率和每10万人病例率；检查图与结果表 |
| Q5聚类 | 对六城标准化特征比较K值并生成聚类图 | 采纳K=2及轮廓系数0.316；保留小样本和指标选择敏感性，不作城市优劣排序 | 重跑聚类、检查标签稳定性和 `validation.json` 31/31通过 |
| 气象口径同步 | 根据统一答复更新温度、降水和降雪说明 | 采纳℉和in/day口径；不修改输入数值，不把周内日均写成周累计 | 对照NOAA源卡和融合表字段说明 |

AI用于阅读、代码、图表和说明初稿，没有生成或补造观测数据。负责人于2026-11-03运行核验脚本、查看两图与结论并核对来源页；最终方法选择、局限和解释由负责人确认。
