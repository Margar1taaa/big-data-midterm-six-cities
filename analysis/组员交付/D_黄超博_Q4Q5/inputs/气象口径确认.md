# 气象单位与周表口径确认

记录日期：2026-10-29。
来源：用户在本聊天中转述收到的气象数据口径答复。此记录属于来源说明，不等同于本次分析重新检查全部原始NOAA文件或清洗脚本。

答复原文：

> 气温单位为华氏度（℉），降水和降雪单位为英寸。
> 周表的prcp_sum和snow_sum实际采用的是“周内日均”口径：先计算各站该周有效观测日的日均降水、降雪，再对站点取平均，不是周累计量。

## 本次使用规则

- `tavg_avg`：气温周表值，单位华氏度（℉）。
- `prcp_sum`：各站该周有效观测日的平均日降水量，再对具有有效值的站点取平均；单位英寸，描述为“周内日均降水”。
- `snow_sum`：各站该周有效观测日的平均日降雪量，再对具有有效值的站点取平均；单位英寸，描述为“周内日均降雪”。
- 两个`_sum`列名沿用交接表以保持兼容，名称中的sum不能解释为周累计。
- 若站点有效天数不同，该口径是站点等权平均，不是把所有站点的观测日合并后统一求平均。
- Q5对这些城市周指标在共同有效周上等周权求均值，再跨城逐列z-score；降水/降雪特征因此是“周内日均值的时段均值”，不是时段累计量。
- 不把现值乘7来猜测实际周累计量：各站有效观测日可能不足7天。
- 现有数值无需换算，更新的是单位、名称和解释。原始站点归属及清洗过程未在本次重新核验。
