# 分析阶段追加口径记录

原交接包已有 `../GAPS.md`（G1–G9 历史缺口及源数据口径）。本文件按分析阶段约定记录新增分析决定，不改写历史记录。

- 2026-10-28｜Q2 滞后相关：流感在平滑、配对前整段排除 1915–1919（包括纽约 1919 年末的少量病例）；每城分别按周日排序，在连续周段内对病例和报刊强词命中率各做完整 4 周滚动均值，不跨 1922→1930 年空档，也不将 NA 补零。滞后 +k 定义为病例第 t 周、媒体第 t+k 周，故正值表示媒体滞后。每城先算 Pearson/Spearman，再以 n−3 加权 Fisher z 汇总六城系数；同时保留各城结果，避免直接拼接原始病例量造成城市规模主导。各城常规 p 值仅作探索性参考（p<0.05 为原口径 04），未校正序列自相关和多滞后择峰，合并结果不作显著性断言；相关不作因果解释。
