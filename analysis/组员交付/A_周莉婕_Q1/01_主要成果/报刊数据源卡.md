# Chronicling America 报刊数据源卡

## 采用结论

**条件采用。** 该数据可生成城市—周—疾病层级的媒体关注代理指标，但必须保留 OCR 误差、多语种、报纸受众偏差和覆盖不均说明。

## 来源与采集记录

- 来源：Library of Congress Chronicling America（NDNP）。
- 内容：历史报纸逐页 OCR 文本、题名、LCCN、期号日期、版次和页码。
- 城市：Baltimore、Cleveland、Los Angeles、Milwaukee、New York、Washington。
- 设计窗口：1915–1922 年和 1930–1932 年；1923–1929 及 1933 年以后不属于本次报刊采集范围。
- 原始形式：逐页 `ocr.txt`；大三城以 zip 流式读取，不依赖全部解压。
- 周标签：报纸日期归入对应周日 `sunday_date`。

## 词表 v2 和指标口径

- 强词（主指标）：`influenz*`、`grippe*`、`diphther*`、`poliomyelitis*`，历史/OCR 变体，以及德语、西班牙语疾病短语。
- 弱词（敏感性分析）：`flu`、`polio`、`antitoxin`；不进入主命中率。
- 主指标：`np_*_rate = 强词命中页数 / 当周扫描页数 × 100`。
- `np_pages=0` 表示无报刊覆盖，命中率为 NA，不是 0%。

## 字段字典

| 字段 | 含义 | 使用规则 |
|---|---|---|
| `city` | 报纸出版城市的标准名 | 不等于每篇报道的事件地 |
| `paper` | 报纸题名 | 用于题名更替和固定效应检查 |
| `sunday_date` | 统一周日标签 | 与 Tycho 和 NOAA 周粒度连接 |
| `n_issues` | 该周扫描期数 | 只用于覆盖说明，不作主分母 |
| `n_pages` / `np_pages` | 该周可检索 OCR 页数 | 主命中率分母 |
| `n_hits_strong` / `np_*_hits` | 强词命中页数 | 主分析分子 |
| `n_hits_weak` / `np_*_hits_weak` | 弱词命中页数 | 只用于敏感性分析 |
| `np_*_rate` | 强词命中页率（%） | 无报刊页面时为 NA |

## 交接核对问题

交接说明称六城共 300,450 页，但两张 cleaned 覆盖表实际合计 299,358 页，相差 1,092 页。差额位于巴尔的摩：`Der Deutsche Correspondent` 少 1,060 页，`Telegraf` 少 32 页。Q1 以交接包已融合的实际周级表为输入，但正式报告需将差异登记到 GAPS，或补扫后重跑融合与 Q1。

## 最大风险

关键词命中是报刊关注代理指标，不等于疫情或公众态度。报纸出版地也不等于报道事件地；多语种、OCR 断词和报纸题名更替可以产生系统性偏差。
