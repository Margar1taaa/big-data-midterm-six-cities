## G2. Tycho 流感缺 1918–1919（大流感窗口） 🔴
- **缺口**：六城 INFLUENZA 记录 1915–1918 均为 0 行，1919 年仅 5 行；系统覆盖自 1920 起、1948 年止（见 `data\cleaned\tycho_coverage_matrix.csv`）。
- **影响**：若核心研究问题涉及 1918 大流感，Tycho 无法支撑，需补源或调整窗口。
- **可选方案**：
  a) 补源：US Mortality Statistics（1920 年前城市死亡周报）或 CDC 1918–1919 流感死亡估计，按城市级补 1918–1919 死亡序列；
  b) 改窗口：流感分析聚焦 1920–1948（28 个流感季），1916–1953 只保留白喉/脊灰两病种；
  c) 用报刊数据描述 1918–1919 疫情关注度（报刊窗口 1915–1922 可覆盖），但缺 Tycho 侧对照。
- **已定（2026-10-21 拍板）**：融合窗口锁定 1915–1922＋1930–1932（11 年）；Tycho 流感 1915–1919 记 **NA**，该段流感关注度由报刊列承担（方案 c 与 a 的折中，不阻塞）；纽约 1919-11-30 起真实流感病例记录如实保留。流感统计描述仅覆盖窗口内 1920–1922＋1930–1932 与纽约 1919 尾。
- **状态**：🟢 已定（2026-10-21）

## G3. 报刊关键词词表与分母口径 🟢（弱词单列已落地）
- **缺口**：三城报纸语种混杂——巴尔的摩为德文报（Der Deutsche Correspondent / Telegraf）、洛杉矶含西文报（La Opinion / La Prensa）、克利夫兰 The Gazette 疑似周报；英文关键词表不覆盖德/西文。
- **词表 v2（2026-10-21 升级，2026-10-22 六城全量跑通）**：词干匹配（influenz*/grippe*/diphther*/poliomyelitis*）+ 历史/OCR 变体（influensa/influenzy、poliomyletis/poliomelitis、diphter*）+ 德西短语（spanische grippe、la grippe、grippe espagnole、gripe española、paralisis infantil、kinderlahmung 系列、membranous croup）。
- **v2 全量结果（2026-10-22）**：三小城重扫 32,036 页——总 2.20%（流感 5.15%、白喉 0.38%、脊灰 1.06%）；大三城 267,322 页——总 2.39%（流感 5.47–6.13%、白喉 0.29–1.36%、脊灰 0.70–1.17%）。六城命中率同量级，口径统一后并入融合表。
- **抽查（2026-10-21，`scripts/spot_check_newspaper.py`）**：27 个 v1 命中页人工核对——约 12 真命中（44%）、14 误报；误报集中在三个弱词：**flu**（德文报街名/断词）、**polio**（西文 pollo"鸡肉饭"/monopolio"垄断"/policy 残片）、**antitoxin**（坏疽抗毒素等非白喉语境）。建议正式指标采用**强词口径**，弱词单列或复核剔除。
- **分母口径（2026-10-22 已定）**：**按页数**＝命中页数÷该周扫描总页数。按期数＝命中期数÷该周总期数 亦可算（hits_weekly 含 n_hits/n_pages、coverage 含 n_issues），但三小城 6 报中 4 家为周报（每周 1 期），按期数对周报退化为 0/1 二值、失去区分度，故弃用为主口径（可作日报子集辅助口径）。
- **状态**：🟢 已落地（2026-10-22 单列）——弱词不再"待拍板"：词表拆 STRONG/WEAK 两组正则（STRONG=词干/变体/德西短语，WEAK=flu/polio/antitoxin），输出 n_hits_strong / n_hits_weak / n_pages；三小城单列重扫验证总命中 2112（strong 1446 + weak 666，与 v2 混合分毫不差，拆分不丢页），大三城单列全量 19,141（strong 11,211 + weak 7,930）；融合表主列用**强词**（np_*_hits），弱词入 *_hits_weak 列与派生列（np_*_rate 基于强词）供敏感性分析
